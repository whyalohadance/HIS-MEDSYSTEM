## 🕷️ XSS PROTECTION — 4 warnings

| Payload | Сохранён в БД | Примечание |
|---------|---------------|------------|
| `<script>alert(1)</script>` | ⚠️ Сохраняется as-is | Frontend использует Angular (автоэкранирование) |
| `"><img src=x onerror=alert(1)>` | ⚠️ Сохраняется as-is | Angular `{{ }}` экранирует HTML |
| `javascript:alert('xss')` | ⚠️ Сохраняется as-is | Безопасно при корректном использовании |
| `<svg onload=alert(1)>` | ⚠️ Сохраняется as-is | Angular-шаблоны не уязвимы |

> **Уровень риска: НИЗКИЙ** — Angular автоматически экранирует все `{{ }}` interpolations. Данные не исполняются при рендере. Тем не менее, рекомендуется добавить серверную санитизацию (пакет `sanitize-html` или class-transformer `@Transform`).
